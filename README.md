# My Awesome Workstation Setup

A personal collection of the tools, services, and configurations I use on my
local workstation across different operating systems. Each setup is automated
through its platform's package manager to keep software installation and updates
centralized and reproducible. Use the corresponding setup link below each table.

In the past, I also used Windows as a server operating system, but I have used
and still use Linux more extensively for server workloads. This repository is
not about server operating systems. It documents the software I rely on day to
day on my local workstation.

> **Philosophy:** Security and privacy come first. I prefer open-source
> solutions whenever possible.
